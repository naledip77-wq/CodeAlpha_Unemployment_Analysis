#📊 Unemployment Analysis in India

CodeAlpha Data Science Internship – Task 2

📌 Project Overview

This project explores unemployment trends in India and investigates the impact of the COVID-19 pandemic on unemployment rates.

The analysis uses Python and data visualisation techniques to identify patterns, compare regional unemployment rates and understand changes over time.

🎯 Project Objectives

- Explore and analyse unemployment datasets.
- Identify unemployment trends over time.
- Investigate the impact of COVID-19 on unemployment.
- Compare unemployment rates across Indian regions.
- Create meaningful data visualisations.
- Present findings based on the analysis.

🛠️ Tools and Technologies

Tool| Purpose
Python| Programming and analysis
Pandas| Data manipulation
NumPy| Numerical operations
Matplotlib| Data visualisation
Seaborn| Statistical visualisation
Google Colab| Development environment

📂 Project Files

- "Task2_Unemployment_Analysis.ipynb" – Jupyter Notebook containing the Python code, analysis and visualisations.
- "Task2_Unemployment_Analysis.pdf" – PDF version of the completed project.

🔍 Analysis Performed

1. Data loading and exploration.
2. Data cleaning and preparation.
3. Unemployment rate analysis.
4. Regional unemployment comparisons.
5. Trend analysis over time.
6. Visualisation of unemployment patterns.
7. Identification of key findings.

📈 Key Findings

The analysis identified:

- Differences in unemployment rates across Indian regions.
- Significant fluctuations in unemployment during the COVID-19 period.
- Variations in unemployment trends over time.
- Regions with comparatively high and low unemployment rates.
